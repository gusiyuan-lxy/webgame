一、诗

玩法：皇帝（主持人）随机说一个主题，三位做出一首诗（限时10分钟）由皇帝（主持人）打分（1-10分），不可质疑皇帝的审美！

评分说明：皇帝将根据诗词的意境、韵律、创意进行评分，每人最高10分，最低1分。

二、乐（本轮淘汰1位练习妃）

玩法：请依次唱出含有十二生肖的歌词。直到胜出人。

奖励：冠军+7分，亚军+3分

注：主持人也可换玩法，不强制要求十二生肖。

比赛规则：按顺序唱出包含生肖动物的歌词，不能重复，唱不出或重复者淘汰。

三、才

玩法：请抢答皇帝出的文化题（每题5分）

A 中秋
B 端午
C 元宵
D 七夕
正确答案：C
2. 问三不知，指的是哪三不知？

B 事情的开始，经过，结果
C 孔子，孟子，老子
D 姓名，籍贯，八字

3. 孙悟空被如来佛压在哪座山下？

B 武当山
C 五台山
D 五指山
